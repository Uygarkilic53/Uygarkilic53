## Featured Projects

### VeloStream — Polyglot Live Streaming Platform

A Twitch-style live streaming web application engineered with a polyglot backend architecture to separate core API workflows from high-concurrency real-time workloads.

**Key features:**

- Polyglot microservices setup combining Node.js (Fastify) for authentication/REST APIs and Go (Fiber) for high-concurrency real-time processing
- Live streaming workflows and real-time viewer interaction
- Relational data modeling with PostgreSQL
- Containerized development and load/smoke testing workflow

**Technologies:** Go (Fiber), Node.js (Fastify), React, PostgreSQL, Docker, k6

[View Repository](https://github.com/Uygarkilic53/VeloStreamWeb)

---

### CHATUKMOBILE — Real-Time Mobile Chat Application

A cross-platform mobile messaging application designed for fast, reliable communication with caching and local offline persistence.

**Key features:**

- Real-time messaging architecture
- Redis caching layer for low-latency data access
- Local SQLite persistence for offline-first message storage
- Cross-platform mobile UI built with React Native
- Scalable Node.js backend API

**Technologies:** React Native, Node.js, Redis, SQLite, WebSockets

[View Repository](https://github.com/Uygarkilic53/CHATUKMOBILE)

---

### E-Commerce Management Platform

A centralized multi-channel SaaS platform designed to unify multiple e-commerce stores and marketplaces into a single operational workspace.

**Key features:**

- Multi-store product, order, inventory, and customer synchronization
- Marketplace, e-commerce, and shipping provider API integrations
- Encrypted API token and credential management
- Role-based access control, audit logging, and KPI dashboards
- Shipment management and automated background workflows

**Integrations include:** Shopify, Amazon, BigCommerce, WooCommerce, Trendyol, Hepsiburada, İkas, PrestaShop, IdeaSoft, and Kargomucuz.

**Technologies:** Next.js, TypeScript, Node.js, Express.js, MongoDB, REST APIs

---

### CinemaHall — Cinema Reservation Platform

A full-stack cinema reservation application with separate user and admin panels plus an AI-assisted recommendation flow.

**Key features:**

- JWT-based authentication and role-based authorization
- Interactive hall and seat selection with real-time reservation flow
- Admin dashboards for managing movies, halls, and bookings
- Gemini AI-powered cinema assistant
- REST API backend with MongoDB persistence

**Technologies:** React, Node.js, Express.js, MongoDB, Mongoose, JWT, Tailwind CSS, Gemini API

[View Repository](https://github.com/uygarkilic53/cinemahallMERN)
